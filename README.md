# Tugas Biodata

Profil singkat biodata yang dibuat menggunakan HTML, dilengkapi foto diri.

## Rangkuman Elemen HTML

| Elemen | Fungsi |
|--------|--------|
| `<!DOCTYPE html>` | Menyatakan bahwa dokumen ini adalah HTML5 |
| `<html>` | Elemen pembungkus seluruh halaman |
| `<head>` | Berisi informasi halaman yang tidak tampil langsung di layar |
| `<meta>` | Berisi informasi tambahan halaman (jenis karakter dan pengaturan tampilan di berbagai layar) |
| `<title>` | Judul halaman, muncul di tab browser ("Profil Biodata") |
| `<link>` | Menghubungkan halaman HTML dengan file CSS |
| `<body>` | Berisi seluruh konten yang tampil di layar |
| `<div>` | Wadah untuk mengelompokkan isi (kotak utama dan bagian "Tentang Diri") |
| `<h1>` | Judul utama halaman ("Profil Biodata") |
| `<h2>` | Subjudul, dipakai untuk "Biodata Diri" dan "Tentang Diri" |
| `<img>` | Menampilkan foto profil |
| `<table>` | Membuat tabel untuk menampilkan data biodata |
| `<tr>` | Baris dalam tabel |
| `<td>` | Kolom/sel dalam baris tabel |
| `<p>` | Paragraf, dipakai untuk teks "Tentang Diri" |

## Rangkuman Atribut HTML

| Atribut | Dipakai di | Fungsi |
|---------|-----------|--------|
| `lang="id"` | `<html>` | Menyatakan bahasa halaman adalah Bahasa Indonesia |
| `charset="UTF-8"` | `<meta>` | Menentukan jenis karakter agar semua huruf tampil benar |
| `name="viewport"` | `<meta>` | Pengaturan tampilan sesuai lebar layar perangkat |
| `content="width=device-width, initial-scale=1.0"` | `<meta>` | Lebar halaman mengikuti layar, zoom awal 100% |
| `rel="stylesheet"` | `<link>` | Menjelaskan bahwa file yang dihubungkan adalah CSS |
| `href="style.css"` | `<link>` | Lokasi file CSS yang dihubungkan |
| `class="container"` | `<div>` | Nama kelas untuk kotak utama agar bisa diatur lewat CSS |
| `class="tentang"` | `<div>` | Nama kelas untuk bagian "Tentang Diri" |
| `src="acu.jpeg"` | `<img>` | Lokasi file gambar yang ditampilkan |
| `alt="Foto Diri"` | `<img>` | Teks pengganti jika gambar gagal dimuat |
